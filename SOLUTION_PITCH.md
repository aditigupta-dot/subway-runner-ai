# Subway Runner – AI-Powered Voice-Controlled Endless Runner

### Problem Statement
Traditional endless runner games rely on keyboard or touch controls. This project explores how AI-powered speech recognition can make gaming more interactive and hands-free.

### Proposed Solution
Subway Runner is a 3D endless runner game that allows players to control their character through spoken commands. It integrates Gnani AI's Prisma Speech-to-Text API to recognize voice commands and convert them into real-time game actions.

### Key Features
- Voice commands: Move left, move right, jump, slide, start, pause, and resume.
- Gnani AI integration: Converts spoken commands into text using Prisma.
- 3D gameplay: Three-lane running environment with trains, barriers, obstacles, and coins.
- Game mechanics: Score tracking, coin collection, increasing speed, collision detection, and restart.
- Alternative controls: Keyboard and touch-based gameplay.

### Technology Stack
- Frontend: React, Vite, React Three Fiber, Three.js
- Backend: Node.js and Express
- AI: Gnani AI Prisma Speech-to-Text API
- Browser APIs: MediaRecorder and Web Audio API

### Impact and Future Scope
The project demonstrates a practical application of speech AI in interactive gaming. Future improvements include multilingual voice commands, spoken AI feedback, improved noise handling, and additional game environments.
